附件已通过 GitHub 的视频上传接口保存，地址由 GitHub 实际返回，绑定本仓库。README 中 URL 单独占一段，前后留空行，GitHub 才会渲染为播放器；不要改成普通 Markdown 链接或图片。视频区域保留 `bread-video` 标记，下方仓库 MP4 链接作为备用下载入口。

更换视频时，上传新附件并保存 GitHub 返回的真实 URL，更新根目录 README 对应标记区域和本表。通过仓库首页和未登录请求核对播放器、公开可见性及视频内容；只推送 MP4 文件或显示静态封面不代表内嵌播放成功。

`shader-debug.gif` 和 `cbuffer-live-edit.gif` 继续以 GIF 在 README 中直接播放。本目录没有对应原始 MP4，转换格式不能恢复已丢失的颜色和细节。其他 PNG/GIF 保留原内容，两个 Unity PNG 封面仍可作为备用素材。

上传规范见 [GitHub 附件说明](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)和 [GitHub CLI 媒体附件说明](https://docs.github.com/en/github-cli/github-cli/attaching-files-with-github-cli)。
