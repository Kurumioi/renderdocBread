# 有界检查点收尾版本

## 版本范围

2026-09-09 用户决定本轮停止扩展检查点体系：大捕获可以自动尝试少量检查点，必须限制
新增存储，无法安全使用或无法证明收益时回退到普通回放。此版不继续开发两套完整资源世界、
任意阶段切片或完整逐 RT 依赖传播，也不恢复旧的静态画面缓存。

默认自动检查点总计费预算最多 **512 MiB**，按捕获大小最多 **2–3 个**，候选尝试有上限。
显式 API/诊断环境的预算覆盖仍可用于受控实验，不代表默认产品策略。此数值是检查点新增
资源与已计费状态的上限，不是整个 RenderDoc 进程的显存/RAM 上限；原始捕获资产、驱动内部
开销与普通回放自身的内存仍存在。D3D11/GL 资源大小使用逻辑估计，Vulkan/D3D12 在可用处
使用分配需求；各后端并不都能精确查询物理显存费用。

## 收尾修复

- D3D12 在加载阶段记录合法边界的描述符脏块费用；准入检查不再始终使用整张描述符表。
  信息未知、堆形状变化或资源/Shader 替换时仍保守计算；实际保存保留最终预算检查。
- 显存紧张时采用有限次数、带间隔的空闲重试，关闭捕获、编辑或新的交互会取消旧任务。
- Vulkan 限制整帧可选绑定证据累计存储与提交扫描工作；超限同时撤销读写证明并回退。
- 检查点 CPU 状态在复制前检查容量；过大的描述、状态或程序数据拒绝创建检查点，避免
  先进行大分配再发现超预算。D3D11、GL/GLES、Vulkan 的新增单点元数据预检上限为 64 MiB。
- 自动试用按检查点累计而非仅按单个 EID 计数；连续拖到不同 EID 不能无限绕过收益评估。
  对照使用用户本次请求的普通回放，不额外插入一轮回放；缺少证据或收益不足的试用会退役。
- 移除未验收的 typed inactive 初值省略实验，保留已有的 typed alias 检查点正确性路径。
- 合成编译修复 AIAssistant 的 Windows 源码编码设置：该文件显式使用 UTF-8，并直接包含
  公共头文件而不复用系统代码页的 PCH，避免主工程新增 Unicode 文案导致 C4819 构建失败。

这些判断依据捕获的实际资源、访问和 API 状态，不包含 `1.rdc`、`6.rdc` 的文件名或固定 EID。
无法证明安全的资源和执行路径继续普通回放，不能把回退解释为支持所有捕获的增量加速。

## 编辑语义

共享 CBuffer 覆盖以原始资源和实际字节范围为对象，包含绑定基址及变量偏移；共用该范围
的消费者会受到影响。当前 EID 不需要改变，但绘制仍需重新执行。已证明位于首次受影响
消费者之前的检查点可以保留，受影响检查点失效；无法证明依赖时扩大失效范围。

Shader 替换采用保守失效和重建，并保留原始资源以便撤销。此版没有承诺只重算几个受影响
RT 的完整依赖图，也不能承诺复杂大帧的任意实时调参都达到 60 fps。

## 已有收益证据

v22 同构建、同进程的开关 A/B 见 [快速对比](EID-Quick-AB-20260909.md)。`1.rdc` 两个测点
热切换改善约 12–13%，`6.rdc` 约 3–14%，仍不足以证明检查点能普遍实现实时拖拽。
所以本版保留有界可选加速，并保留不依赖检查点的 UI 调度、合法向前执行、差异恢复等优化。

v22 空闲 GPU 下额外自动创建验证：`auto-main1-pre-final-v22.json` 实际构建 1 个检查点，
5 次往返命中，新增计费 61,329,408 B（58.49 MiB），完整颜色/深度对照通过。
这是旧构建的对照记录，最终收尾改动以本版验收结果为准。
