# RenderDocBread 1.13.124

Unity restoration now defaults to a clean final asset tree and a saved `.unity`
scene that opens through the normal Editor without construction or setup commands.
After successful verification, remove task-generated builders, validators,
comparison images and intermediate exports. Keep requested final renders,
necessary rendering/inspector code, user files and unfinished recovery checkpoints.
Store provenance and verification evidence in Bread task storage.

The asset layout planner supports Scenes, Shaders, Runtime and Editor alongside
Models, Materials, Textures and Prefabs, creating only needed folders. The handoff
review observes listed temporary-file and `.meta` residue, missing final files,
runtime-purpose annotations and post-cleanup scene-reopen observations bound to
the saved scene's SHA-256. Observations remain advisory; the Agent still checks
actual final Scene/Game output and repairs concrete problems.

Includes all released 1.13.123 offline settings, Codex startup diagnostics and
Windows long-path/build compatibility fixes. Existing project names, paths,
stored records and the main checkout's separate uncommitted work are preserved.
