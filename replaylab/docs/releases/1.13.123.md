# RenderDocBread 1.13.123

Windows x64 完整 standard 便携版。本版继续修复 Codex 订阅启动和构建兼容问题，包含 1.13.122 的离线 AI 配置修复。

- 修复 Codex 通过 npm 的 `codex.cmd` 启动时，完整 MCP 配置超过 Windows CMD 长度限制、返回“命令行太长”的问题。任务配置改用私有参数文件，官方 npm 安装优先直接启动原生程序或 Node 入口；保留原有工具范围和权限约束。
- 修复中文启动错误的乱码，支持 UTF-8、Windows OEM/ANSI 和 UTF-16 错误输出。
- 启动失败时，在 `%LOCALAPPDATA%/ReplayLab/logs` 生成 UTF-8 诊断报告，记录实际程序、工作目录、退出码、参数长度、环境变量长度、PATH 概况和解码方式。错误提示提供报告位置。凭据值及非必要环境变量值隐藏，报告自动轮换保留最近 20 份。
- 修复 Issue #2：依赖还原、校验、源码复制和临时目录清理使用 Windows 长路径接口；枚举失败保留现有依赖，不反复误判损坏；清理失败单独提示，不再把已验证成功的程序包误报为失败。
- UEX 离线构建固定使用 .NET SDK 10.0.302 与 apphost/runtime 10.0.10，缺少时在原生编译前明确提示。用户程序包仍自带 .NET 运行库，无需安装 SDK。
- CI 检查本次引入的提交和代码行，并增加实际 Windows 配置、订阅、进程与打包回归；原上游旧工具链矩阵保留为手动工作流。

标注功能继续保留在独立开发分支，不包含在本次发布中。请将完整 ZIP 解压到新的可写目录使用；现有连接及用户项目路径保持兼容。
