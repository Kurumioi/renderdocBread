# RenderDocBread 1.13.125

修复 CodeBuddy 连接成功后，聊天因 `codebuddy.ai/command` 扩展通知触发
`PolicyError` 而被 Bread 主动取消的问题。

- 按 [ACP 扩展规范](https://agentclientprotocol.com/protocol/v1/extensibility)
  忽略未处理的扩展通知；未知扩展请求返回 JSON-RPC `-32601`，允许厂商回退。
  这适用于全部 ACP 提供商，不依赖容易过期的通知名称白名单。
- 通知内容不执行命令、不授予权限，也不作为任务完成凭据。文件、终端、MCP
  授权和实际的响应结束/错误仍由各自的现有检查处理。
- 成品离线协议自检新增模型响应及连续两轮流式聊天，穿插 CodeBuddy 初始化、
  command 和未知扩展事件，通过真实 ACP SDK 与独立 stdio 进程验证。
- CI 新增 ACP 扩展、主对话会话、连接边界及离线协议自检回归。

此版本保留 1.13.124 的全部修复和完整 standard 发行内容。Native 源码及封存
依赖未变化时，按增量发布规范复用校验过的 1.13.124 原生工件，重新冻结全部
受影响的 Host，并对新归档执行审核、编译器能力和重定位启动检查。

本地没有 CodeBuddy CLI 或已登录的 CodeBuddy 连接；离线协议和成品自检
不代表真实订阅账号的认证、模型可用性或配额已经验收。用户仍需提供自己的
官方 CLI 和账号。发布不修改当前运行实例，不包含账号、聊天或用户工程。
