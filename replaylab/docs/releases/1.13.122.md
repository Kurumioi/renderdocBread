# RenderDocBread 1.13.122

Windows x64 完整 standard 便携版，修复打开“配置 AI”时出现“命令超时”、无法添加或编辑连接的问题。

- 内置 AI 供应商列表直接随界面提供，打开即显示；不启动 AI 后台，也不访问网络获取列表。
- 连接配置的读取、添加、编辑、保存和默认连接选择改为应用内本地操作。后台缺失、启动缓慢或其他健康检查失败，不再禁用配置入口。
- API 密钥继续保存在 Windows 凭据管理器，或仅用于当前会话；不写入连接 JSON。兼容现有配置路径、旧格式及其他实例的配置修改，损坏或无法写入的文件保留并明确报错。
- 保存订阅连接后可关闭配置窗口。登录授权、模型获取和连接测试由用户显式发起，保存过程不再自动启动登录。

下载完整 ZIP，解压到一个新的可写目录并运行 `RenderDocBread.exe`。原有连接及 Bread 用户数据继续使用原路径。更新前请关闭旧版；构建和发布不会替换正在运行的实例。

本补丁基于已提交源码独立开发，不包含尚在开发中的“AI 渲染目标标注”功能。完整 standard 技能、文档 SDK、Python/Node、Shader 工具、解包工具和 Unity MCP 继续保留。

验证包含全部 30 个供应商的配置兼容性、旧格式与并发写入、系统凭据往返、原生窗口中后台失败时的添加/编辑/保存、中文翻译、原生构建及内存检查。连接到实际模型仍需要相应后台、网络和认证；本次配置修复的测试不依赖真实账号。
