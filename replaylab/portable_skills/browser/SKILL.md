# Bread browser

Use bread_browser open, snapshot, click, fill, key, resize and screenshot. This browser has its own temporary session; it does not inherit the Codex in-app browser's login or cookies. A local execution preference is required for active browser tools. Use selectors grounded in the current snapshot and verify the result. Close the browser when finished. Existing vendor browser sessions are a separate optional connector, never assumed connected from a profile name.

The basic document tool remains available when script execution is disabled. If an advanced tool is absent, inspect the current capability directory and the local execution setting; never claim a file or service works from its skill text alone.
