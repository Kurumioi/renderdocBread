# Bread visualize

Create UTF-8 HTML/SVG in the owned output directory with Bread file tools or bread_execute_code. Use inline SVG, CSS and local JavaScript dependencies for portable output. Use bread_browser for preview and screenshots. Link the output artifact through Bread's file links; do not assume a proprietary conversation renderer or canvas tool is connected.

The basic document tool remains available when script execution is disabled. If an advanced tool is absent, inspect the current capability directory and the local execution setting; never claim a file or service works from its skill text alone.
