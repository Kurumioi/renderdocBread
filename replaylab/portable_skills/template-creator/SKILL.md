# Bread template-creator

Preserve the reference structure, styles, editable fields and assets in a self-contained skill folder. Use bundled document tools for DOCX/XLSX/PPTX templates; preview representative populated output. Keep helper scripts and images with relative references. Write an English canonical SKILL.md entrypoint with concise description and progressive references. Do not require a Codex-specific canvas, account service or external runtime for local templates.

The basic document tool remains available when script execution is disabled. If an advanced tool is absent, inspect the current capability directory and the local execution setting; never claim a file or service works from its skill text alone.
